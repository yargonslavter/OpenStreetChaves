# OpenStreetChaves

Repositório dedicado para engenharia reversa e melhoria do antigo jogo brasileiro chamado Street Chaves.

# Requisitos mínimos para construir o jogo
Instale a versão do Lazarus 4.8 oficial (https://www.lazarus-ide.org/).

Abra o projeto, no menu Executar -> Construir (ctrl+F9).

Pronto! O executável StreetChaves.exe deverá aparecer na raiz e é só abrir.

# Controles do jogo
As teclas para jogar o Open Street Chaves são:
* Direcionais para mover e navegar;
* Tecla ESC: Fecha o jogo;
* Tecla 5: Serve para dar fichas (pois o jogo simula uma máquina de fliperama);
* Teclas 1 e 2: Opção de escolher com qual player jogar (precisa ter fichas);
* Tecla P: Pausa o jogo;
* Tecla G: Lista de golpes do lutador;
* Teclas "-" e "=": Muda a velocidade do jogo;
* Teclas "Z", "X", "C", "V": Golpes (soco baixo, soco alto, chute baixo, chute alto), a tecla "Z" também é usada para confirmar escolhas;
* Tecla F1: Configurações do jogo;
* Tecla F2: Remapear controle do jogador 1.

# Bugs conhecidos
* A versão atual somente roda em Windows;
* Resolução em tela cheia ainda não é funcional;
* Não é possível utilizar Joysticks (somente o teclado).
